# Desserts E-Commerce Web App

A responsive, single-page e-commerce web application built with **React**, **TypeScript**, and **Tailwind CSS**. Users can browse a product grid, manage their cart in real time, and confirm orders with an overlay summary modal.

## Features

- **Interactive Product Cards:** Buttons switch seamlessly between an "Add to Cart" state and increment/decrement quantity controls.
- **Dynamic Sidebar Cart:** Live updating of item counts, unit prices, and total cost calculations with one-click item removal.
- **Order Confirmation Modal:** Overlay display summarizing ordered items and total bill breakdown upon checkout.
- **Responsive Design:** Optimized layout for mobile, tablet, and desktop viewports.
- **Strict Type Safety:** Fully typed props, interfaces, and component architectures using TypeScript.

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Icons:** React Icons (`react-icons`)
- **Build Tool:** Vite
